Tổng quan về Tingee

Tingee là nền tảng thanh toán tích hợp giúp merchant kết nối với nhiều cổng thanh toán — Bảo Kim, OnePay, Payoo — thông qua một API duy nhất, đơn giản hoá quy trình tích hợp và quản lý giao dịch. [NỘI DUNG CHỜ CẬP NHẬT — thay bằng mô tả chính thức khi có]

Thông tin

Trang tài liệu này đang trong quá trình xây dựng. Nội dung chi tiết sẽ được cập nhật sau khi có tài liệu chính thức từ chủ dự án.

  • Hỗ trợ kỹ thuật 24/7

Các bước onboarding

  1. Đăng ký tài khoản merchant — Điền form đăng ký trên portal Tingee và xác nhận email.
  2. Xác thực danh tính (KYC) — Cung cấp giấy tờ pháp lý theo yêu cầu.
  3. Cấu hình cổng thanh toán — Chọn và kích hoạt Bảo Kim / OnePay / Payoo trong dashboard.
  4. Kiểm thử trên Sandbox — Dùng API key sandbox để chạy giao dịch thử, kiểm tra callback.
  5. Chuyển sang Production — Thay API key production và thực hiện go-live.

Cảnh báo

API key production và sandbox hoàn toàn khác nhau. Không dùng key production trong môi trường kiểm thử để tránh phát sinh giao dịch thật.

Ví dụ khởi tạo thanh toán

Gửi POST request tới endpoint Tingee với body JSON như sau:

JSON — Request khởi tạo thanh toán 
{
  "merchant_id": "YOUR_MERCHANT_ID",
  "api_key":     "YOUR_API_KEY",
  "amount":      100000,
  "currency":    "VND",
  "gateway":     "baokim",
  "order_id":    "ORD-2024-001",
  "description": "Thanh toán đơn hàng #001",
  "return_url":  "https://your-site.com/payment/callback",
  "cancel_url":  "https://your-site.com/payment/cancel"
}

Mẹo

Dùng môi trường Sandbox để kiểm thử toàn bộ luồng thanh toán — bao gồm cả callback / webhook — trước khi go-live. Xem hướng dẫn tại Cấu hình tài khoản.
